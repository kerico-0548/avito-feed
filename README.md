## Обновление

Действующие объявления и прямые уточнения владельца важнее старых материалов. Условия разных направлений не объединяем: возврат в ML — **до 75%**, в помощи студентам — **до 50%**. Для технических заказов от **5000 ₽** предоплата **50% после промежуточного результата**.

После изменения текстов и прайсов: `python feed/build_feed.py`. Сборщик обновляет `feed/avito.xml`, сохраняя состав из `feed/ads.json`. Нельзя удалять записи из списка только ради уборки: это может повлиять на размещение объявлений. Фотографии доступны Авито по ссылкам из ветки `main`; сохраняйте их пути.

Проверка подключения к Авито: `python feed/check_avito.py --all-items`. Ключи читаются из `.env`, токен остаётся в памяти. Результаты сохраняются только локально в скрытой папке `.local/`.

## Тест описания в Волгограде

По запросу владельца от 04.11.2026 только `ai-lessons-volgograd-1` использует [отдельный текст](ads/ai-lessons/variants/volgograd.md). Поле `text_file` в `feed/ads.json` задаёт путь относительно папки направления. Общий `ads/ai-lessons/text.md`, общий сборник пяти текстов и FAQ относятся к основной версии для остальных городов; условия и цены теста совпадают с ней. Меняется только описание: заголовок, фото и остальные поля объявления сохранены. До решения владельца тест не распространять на другие города.

С 11.11.2026 обучение ИИ скрыто целиком; текст теста сохранён как материал для возможного возобновления.
