Актуальные материалы пяти направлений. Источник: тексты и скриншоты владельца, обновление **30.10.2026**. Стаж: **10 лет программирования, 6 лет ML, 4 года ИИ**.

| Направление | Папка | Основная цена |
|---|---|---|
| Помощь студентам | [ads/programming](ads/programming) | **700–1000 ₽/час** |

В каждой папке: `text.md` — текст объявления, `price.md` — прайс и заголовок для автозагрузки, `photos/` — фотографии в порядке показа. Общий файл [Тексты_объявлений_Новые.md](Тексты_объявлений_Новые.md) содержит все пять текстов.

- [Города.xlsx](Города.xlsx) — размещения по пяти направлениям, сверены через API: **127 активных объявлений** на 30.10.2026. Население сохранено из исходной таблицы.
- [FAQ.xlsx](FAQ.xlsx) — вопросы и ответы, включая помощь студентам.
- `originals/` — личные исходники фотографий.
- `profile/photos/` — картинки профиля Авито.
- `feed/` — действующая автозагрузка. Список фида содержит **129 записей**; он отличается от списка 127 активных объявлений. Записи и их идентификаторы при уборке сохранены.
- `.env` — ключи Авито, **только локально**, исключены из Git.

## Обновление

Действующие объявления и прямые уточнения владельца важнее старых материалов. Условия разных направлений не объединяем: возврат в ML — **до 75%**, в помощи студентам — **до 50%**. Для технических заказов от **5000 ₽** предоплата **50% после промежуточного результата**.

После изменения текстов и прайсов: `python feed/build_feed.py`. Сборщик обновляет `feed/avito.xml`, сохраняя состав из `feed/ads.json`. Нельзя удалять записи из списка только ради уборки: это может повлиять на размещение объявлений. Фотографии доступны Авито по ссылкам из ветки `main`; сохраняйте их пути.

Проверка подключения к Авито: `python feed/check_avito.py --all-items`. Ключи читаются из `.env`, токен остаётся в памяти. Результаты сохраняются только локально в скрытой папке `.local/`.
