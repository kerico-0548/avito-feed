# Объявления на Авито

Все материалы по объявлениям в одном месте: тексты, прайсы, фото и города. Отсюда же Автозагрузка Авито берёт фид и фото.

## Структура

```
profile.md            единая информация обо мне: опыт, цены, условия, стиль текстов
cities.xlsx           в каких городах какие объявления размещены
profile/photos/       картинки для профиля Авито
ads/
  tutoring/           репетиторство по информатике
  ml/                 машинное обучение и автоматизация
  ai-lessons/         индивидуальное обучение ИИ (пакеты)
  ai-course/          курс «Введение в ИИ» на Stepik
materials/
  knowledge-base.md   база знаний для ответов клиентам
  faq.xlsx            частые вопросы и ответы
  ad-texts-original.md  тексты объявлений до правок
  archive/            старые и неиспользуемые картинки по направлениям
  my-photos/          исходные фото меня
feed/                 фиды Автозагрузки и скрипты (ведётся отдельно)
```

В `materials/` часть цифр старая (стаж, цена курса 1250 ₽ в FAQ). Если что-то расходится, верным считается `profile.md`.

В каждой папке направления:
- `text.md` описание объявления, как оно идёт на Авито
- `price.md` заголовок, цена в объявлении и подробный прайс
- `photos/` фото по порядку показа: `01` обложка, дальше `02`, `03`… Не больше 10

## Правила

1. Факты (стаж, цены, условия) сначала меняем в `profile.md`, потом в текстах и на картинках.
2. Направления не смешиваем: в каждом объявлении только своя услуга.
3. Новое фото кладём под **новым именем** (например `03b.png`), а не поверх старого. Авито запоминает фото по ссылке и замену под тем же именем не подтянет.
4. Имена файлов только латиницей и цифрами, без пробелов.
